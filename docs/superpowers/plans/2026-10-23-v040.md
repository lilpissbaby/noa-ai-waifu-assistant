# Waifu Desk 0.4.0 — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Personajes con filtros y modo +18 con salvaguardas, Azure con políticas por petición, voces locales Piper, ocho funciones de productividad y skins Live2D (VTuber), en una sola release 0.4.0.

**Architecture:** Lógica pura en módulos pequeños de `src/main/` (personas, productividad, voces, Live2D) probados con `node:test`; las herramientas nuevas siguen el patrón `{ name, description, schema, group, confirm?, run }` y reciben servicios de `main.js` por inyección (`buildToolbox(cfg, getParentWindow, services)`). En el renderer, Piper corre en un Web Worker del avatar y Live2D es un tercer renderizador con la interfaz común de la 0.3.0.

**Tech Stack:** Electron 44, módulos ES sin bundler (import map con hash en la CSP), onnxruntime-web 1.30 (ya incluido), `fflate@0.8.3`, `ical.js@2.2.1`, `pdfjs-dist@6.4.299`, `@mozilla/readability@0.6.0`, `linkedom@0.18.14`, `pixi.js@8.22.0`, `untitled-pixi-live2d-engine@1.4.0`.

**Spec:** `docs/superpowers/specs/2026-10-23-v040-design.md`
